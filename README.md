# Spacers Skeleton

Starter project (starter kit) for rapidly creating new applications based on [Spacers Framework](https://github.com/arturproj/spacers-framework), the MVC micro-framework for PHP 8.

It provides a ready-made folder structure and basic configuration (routing, controllers, entry point), so you can start developing immediately without having to set up the project from scratch.

## Requirements

- PHP >= 8.0
- Composer

## How to get started

```bash
git clone https://github.com/arturproj/spacers-skeleton.git project-name
cd project-name
composer install
```
